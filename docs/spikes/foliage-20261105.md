# Host-authoritative foliage breaks

The owner reports that a shrub broken by the host's car stays intact visually on the guest. Foliage can be a `BP_Crash_Complex_Foliage_Base_C` actor or a mesh instance inside an `InstancedStaticMeshComponent`; matching only actors missed the second representation.

`foliage.lua` records a host foliage actor's mesh and last intact position once per break. Optional `foliage` negotiation enables reliable, world-scoped break notifications. The guest breaks a matching local foliage actor or removes the matching instance of the same mesh within 100 uu. Instance searches run in bounded slices (64 instance queries / 2 ms per tick), and missing streamed-out targets retry for up to five minutes. No guest chassis simulation is enabled. Original positions are retained so flying broken debris cannot produce further break locations. Records replay after a guest finishes admission.
